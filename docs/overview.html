Signal flow

Clairvoyance sends one /tts/stream request per sentence. DragonTTS resolves a cache key — if the clip exists and hasn't expired, it streams back instantly; otherwise it synthesizes live and stores the result.

04 /

Cache policy

LENGTH-SCALED TTL
ttl = clamp(48h + 6h·words, 48h, 6d)
48 h floor6 d cap 1w5w10w≥16w → cap

Longer phrases live longer — the scripted lines worth caching. A purge sweep reaps expired rows + blobs every 20 min.

write-through

every MISS is stored on the request path — recurring phrases cache themselves.

single-flight + INSERT OR IGNORE

one key = one row, one file — never duplicates, even under concurrency.

predictive warm · stitch · pass-through

retired (off). write-through is the whole cache now.
